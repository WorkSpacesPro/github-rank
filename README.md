# 🔥 GitHub 开源排行榜 (GitHub Open Source Rankings)

> 极简、极速、全自动的 GitHub 开源项目趋势榜单。

一个基于 **GitHub Actions** + **原生三剑客 (HTML/CSS/JS)** + **Cloudflare Pages** 搭建的高性能排行榜。每天自动抓取 GitHub 最新数据，支持按需加载、中英双语切换、无极暗黑模式与前端实时搜索。

🔗 **在线演示**: [在线演示](https://org.ooo/github-rank/)  *(请替换为你的真实域名)*

---

## ✨ 核心特性

- ⚡ **极致秒开**：摒弃庞大的框架，原生 JS 驱动。采用**按需加载（拆包）**策略，点哪个分类才拉取哪份 JSON，首页加载几乎零延迟。
- 🌓 **无极暗黑模式**：支持系统级深浅色跟随，点击右上角小太阳，带有丝滑的**水波纹扩散动画**。
- 🌍 **中英双语无缝切换**：全站文案、分类标签、数据表头均支持中文/英文实时切换，状态自动保存于本地。
- 📊 **多维数据榜单**：涵盖总榜、明日之星、AI Agent、自托管、SaaS 模板、各主流语言等 **18 个精细化分类**。
- 🔍 **前端搜索与排序**：内置毫秒级搜索过滤，点击表头（Stars/涨星/语言）瞬间完成升序/降序排列。
- 🏅 **荣誉榜单呈现**：前三名自带金银铜牌，4-10 名加粗高亮，数据一目了然。
- 🛠️ **完全可配置**：导航菜单、站点信息、数据分类全部解耦为 JSON 配置文件，无需改代码即可增删内容。

---

## 🚀 自动化架构

本项目采用 **"前端纯静态 + 后端全自动"** 的 Serverless 架构：

1. **数据抓取 (Python)**：每天定时（或手动）触发 GitHub Actions，运行 `github_rank.py`。
2. **数据拆包**：脚本将抓取到的数据对比历史快照计算“涨星”，按分类生成独立的英文命名 JSON 文件（如 `python.json`）存入 `data/` 目录。
3. **自动提交**：Actions 自动将生成的数据 Commit 并 Push 回仓库。
4. **自动部署**：Cloudflare Pages 监听到仓库更新，自动拉取最新代码构建并分发至全球 CDN。
