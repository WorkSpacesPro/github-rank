关于本项目

最后更新：2026-11-11

这是一个基于 GitHub Actions 和 Cloudflare Pages 搭建的自动化开源排行榜。旨在帮助开发者快速追踪开源社区的流行趋势，所有数据每日自动抓取并更新。

核心特性

  • 多维度分类：涵盖全站总榜、各主流语言（Python, JS, TS, Rust, Go 等）以及热门领域（AI, Cloudflare 生态等）。
  • 涨星追踪：与历史快照自动对比，精准计算项目每日的 Star 增长量。
  • 极速体验：原生 HTML + CSS + JS 构建，无庞大框架依赖。极简黑白灰设计，自带深色模式与前端秒级搜索排序。

技术栈

  • 数据采集：Python 3.11 (Requests)
  • 自动化部署：GitHub Actions (Cron 定时任务)
  • 前端展示：原生 HTML + CSS + JS
  • 静态托管：Cloudflare Pages / GitHub Pages
