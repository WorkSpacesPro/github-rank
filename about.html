关于本项目

Last updated: 2026-11-11

这是一个基于 GitHub Actions 和 Cloudflare Pages 搭建的自动开源排行榜。


为什么做这个？

为了快速追踪开源社区的流行趋势，所有数据每日自动更新。


技术栈

  • Python (数据抓取与对比)
  • GitHub Actions (自动化任务)
  • 原生 HTML + CSS + JS (极简前端)
